## Application rules

- Use TanStack Start file-based routing and Tailwind v4 because this workspace does not support Next.js.
- Keep this exact-reference landing page as one scrolling route; navigation targets the reference page's corresponding sections.
- Store downloaded reference media as Lovable asset pointers and import their URLs, keeping raw media outside the source tree.
- Quote requests open an email draft and tracking opens the original portal; do not imply a connected logistics service exists.
